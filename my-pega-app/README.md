# My Pega App

Application React initialisée avec Vite et structurée pour utiliser le SDK React de Pega.

## Scripts

- `npm run dev` : démarre le serveur de développement.
- `npm run build` : construit la version de production.
- `npm run preview` : prévisualise la version de production.

## Configuration

La configuration Pega se trouve dans `src/config.js`. Adaptez les valeurs à votre environnement Pega.
